# PIRAJIN Personal Website — GitHub Pages Demo

This is the static demo version of the current Personal Website V2 design.

## GitHub Pages

Upload `index.html`, `style.css`, and the `static` folder to the root of the repository, then use:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

The Flask admin/backend is not included in this public demo page.
